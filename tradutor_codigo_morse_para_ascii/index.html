Como funciona o Código Morse?

O Código Morse é um sistema de comunicação criado no século XIX que representa letras, números e pontuações através de um sinal codificado enviado de modo intermitente. Ele é composto por duas unidades básicas: o ponto (.), que é um sinal curto, e o traço (-), que é um sinal longo (equivalente a três pontos).

As letras são formadas por combinações de pontos e traços. Por exemplo, a letra "A" é .- e a letra "E" é apenas .. Para separar as letras de uma mesma palavra, usamos um espaço. Para separar palavras diferentes, usamos 3 espaços (ou uma barra /).

Por baixo dos panos: A Máquina de Estados

Este tradutor não usa um dicionário simples (chave-valor). Ele modela uma Árvore de Transição (Trie). Cada caractere Morse lido (. ou -) move o cursor para um novo estado interno na árvore através da Função de Transição (δ). Ao ler um espaço, o sistema verifica se o estado atual é de aceitação, imprime o ASCII, e retorna ao Estado Inicial (q₀).
